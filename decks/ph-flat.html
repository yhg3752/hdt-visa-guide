필리핀 전자입국신고 안내

필리핀 입국·출국 시 작성하는 전자 여행 신고(eTravel) 안내입니다.

i

eTravel이란?

  • 필리핀 입국·출국 모든 여행자가 작성하는 전자 여행 신고입니다.
  • 건강 신고(eHDC)와 세관 신고가 통합되어 있습니다.
  • 입국 72시간(3일) 전부터 작성하며 무료입니다.
  • 2024년부터 계정 생성(이메일 인증) 후 이용합니다.
  • 발급된 QR(녹색/적색)을 탑승 전 항공사에 제시합니다.

가족·동반자는 한 계정에서 각자 개별 등록합니다(아동 포함). 녹색 QR은 신속 통과(Express Lane)입니다.

Step 01 / 8

eTravel 접속 · 계정 만들기

공식 사이트에 접속해 계정 생성을 시작합니다.

  1. 1etravel.gov.ph에 접속합니다. (eTravel은 무료 · 우측 상단에서 한국어 선택 가능)
  2. 2첫 화면에서 '로그인하려면 여기를 클릭하세요'를 누릅니다.
  3. 3로그인 화면 하단의 '계정 만들기'를 선택합니다. (기존 계정이 있으면 이메일·비밀번호로 로그인)
  4. 4사용할 이메일 주소를 입력하고 '계속'을 눌러 계정 생성을 진행합니다.

비밀번호 만들기 · OTP 인증

비밀번호를 설정하고 이메일 OTP로 인증합니다.

  1. 1새 비밀번호 만들기 — 최소 12자 이상, 대·소문자 각 1자·특수문자 1자·숫자 1자를 포함해 입력하고 비밀번호 확인까지 입력합니다.
  2. 2'계속'을 누르면 일회용 비밀번호(OTP) 입력 화면이 열립니다. 가입 이메일로 6자리 OTP가 전송됩니다.
  3. 3이메일에 도착한 OTP 코드(예: 855033)를 확인합니다. (도착까지 최대 3분 소요 · 스팸함 확인)
  4. 4OTP 6자리를 입력하고 '계속'을 눌러 계정 인증을 완료합니다.

Step 03 / 8

개인정보 · 거주지 입력 · 확인

개인정보와 거주지를 입력하고 최종 확인 후 제출합니다.

  1. 1여권 유형(외국 여권 소지자)을 선택하고 상단 'Take a photo or upload a file'로 사진을 등록합니다.
  2. 2이름·성·성별·생년월일·휴대폰·시민권·출생국가·여권번호·발급기관·발급일·직업을 여권과 동일한 영문으로 입력하고 '다음'을 누릅니다.
  3. 3영주 국가와 거주지 영문 주소(번호/건물/시/주/도)를 입력합니다.
  4. 4마지막 확인 화면에서 입력 정보를 검토하고 'Submit'을 눌러 제출합니다.

Step 04 / 8

새 여행 신고 · 항공편 정보 입력

여행을 신고하고 항공편·여정 정보를 입력합니다.

  1. 1대시보드에서 '새 여행 신고 (VIA AIR or SEA)'를 눌러 여행 등록을 시작합니다.
  2. 2여행 등록 — '본인(FOR ME)' · 항공(AIR) · 필리핀 입국을 선택하고 '계속하다'를 누릅니다. (도착·출발 72시간 전부터 등록 가능)
  3. 3여행 목적·항공사·항공편명(예: KE123)·원산지·출발 공항·출발일을 입력합니다. (환승 시 '환승 있음' 체크)
  4. 4도착일·목적지 숙소(거주/호텔·리조트/경유)를 입력하고 '다음'을 누릅니다. (무비자 입국 가능 국적 안내 확인)

Step 05 / 8

건강 · 세관 · 수하물 신고

건강 신고서와 세관·수하물 정보를 작성합니다.

  1. 1건강 신고서 — 최근 30일 여행 이력(있으면 방문·경유 국가 추가)·전염병 접촉·증상 여부에 답합니다. (허위 신고 시 처벌 대상)
  2. 2세관·통화 신고 — 수하물 신고서와 일반 선언을 확인하고, 5만 페소 또는 1만 달러 이상 반입 시 신고합니다. (신고할 현금이 있으면 '예', 없으면 '아니요')
  3. 3기타 여행 정보 — 동반 가족 인원(18세 미만/이상)과 위탁·기내 수하물 개수를 입력합니다.
  4. 4필리핀 첫 방문 여부를 선택하고 '다음'을 누릅니다.

Step 06 / 8

세관 신고서 서명 · 가족 구성원 확인

세관 신고서에 서명하고 동반 가족 여부를 확인합니다.

  1. 1세관 신고서 서명 — 서명란에 직접 서명합니다. (잘못되면 우측 상단 초기화 버튼으로 다시 서명)
  2. 2서명은 진술 내용이 사실이며 정확함을 증명하는 것으로, 허위 진술 시 처벌 대상입니다. 서명 후 '다음'을 누릅니다.
  3. 3가족 구성원 화면에서 동반 가족이 있으면 '가족 구성원 추가'로 등록합니다. (선택된 가족의 신고서도 함께 생성)
  4. 4동반 가족 없이 진행하면 확인 팝업이 뜹니다. 혼자면 '예'를 눌러 다음으로 진행합니다.

Step 07 / 8

최종 확인 · 선언서 서명 · 제출

전체 입력 내용을 확인하고 서명 후 제출합니다.

  1. 1최종 확인 화면에서 개인정보·영주 거주 국가·여행 정보·수하물 개수를 검토합니다.
  2. 2이어서 항공편·목적지·건강 신고서·세관 일반 신고 내용이 여권·여정과 일치하는지 확인합니다.
  3. 3하단 선언서 서명란에 직접 서명합니다. (진술 내용이 사실임을 증명 · 허위 시 처벌)
  4. 4보안 확인 후 '제출하다'를 누르면 등록이 완료되고 eTravel QR이 발급됩니다. (탑승·입국 시 제시)

Step 08 / 8

등록 완료 · eTravel QR 발급

발급된 QR 코드를 저장해 입국 시 제시합니다.

  1. 1제출이 완료되면 Duty Free 쇼핑 안내 팝업이 뜹니다. (닫아도 등록에는 영향 없음)
  2. 2발급된 eTravel QR 코드에는 성명·참조번호(Reference Number)·항공편·도착 정보가 표시됩니다.
  3. 3입국 시 여권은 이민국(Immigration) 심사관에게, QR 코드는 세관(Customs) 심사관에게 제시합니다.
  4. 4QR을 캡처·촬영 또는 저장·인쇄하여 보관합니다. (QR은 도착 예정일 다음날까지 유효)
